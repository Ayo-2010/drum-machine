# Drum Machine

Eight drum pads that synthesise their sound in the browser, with keyboard controls and a volume slider.

## Features

- Kick, snare, hi-hat, clap, tom, rim, cowbell and crash
- Every sound is generated with oscillators and noise buffers, no audio files
- Click a pad or press keys 1 to 8
- Volume slider
- Pad flash animation on each hit

## Running it

Open `index.html` in a browser. Audio starts after the first interaction, as browsers require.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour and sound synthesis
```

## Tech

Plain HTML, CSS and JavaScript with the Web Audio API.
